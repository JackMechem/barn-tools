# jackshed

A collection of free, browser-based practice tools for musicians — a jam tune picker, a
metronome, a tuner, a note trainer, an audio slow-downer/looper, and a multitrack recorder.
Everything runs locally in your browser; nothing is uploaded anywhere.

**Use it:** [jackshed.com](https://jackshed.com)

**Found a bug, or want a feature?** Please [open an issue](https://github.com/JackMechem/jackshed.com/issues).
